# Sugestão de divisão de tarefas

Ajuste os nomes e a quantidade de integrantes conforme a equipe.

| Integrante | Responsabilidade principal | O que deve saber explicar |
|---|---|---|
| Pessoa 1 | Upload, validação e limpeza | Leitura dos formatos, esquema, dados ausentes e duplicidades |
| Pessoa 2 | Dashboard e visualizações | Filtros, indicadores, gráficos e mapa |
| Pessoa 3 | Machine Learning | Pré-processamento, divisão treino/teste, modelos e métricas |
| Pessoa 4 | Interface, documentação e testes | Fluxo do Streamlit, previsão, README e testes automatizados |

Todos os integrantes devem conhecer o fluxo completo da aplicação, porque o professor pode fazer perguntas sobre decisões gerais do projeto.
